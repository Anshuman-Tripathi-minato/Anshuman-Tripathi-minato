## My GenAI engineering focus

- **Agentic workflows:** connecting LLMs to tools, APIs, and repeatable multi-step tasks.
- **RAG:** grounding responses in relevant source material and improving retrieval quality.
- **Evaluation & reliability:** testing output quality, failure cases, latency, and tool behavior.
- **Backend systems:** building the APIs, data flows, and infrastructure AI applications need.

## Tools I work with

**AI & data:** Python · LLM APIs · MCP/tool integration · RAG · Embeddings · NumPy · pandas · scikit-learn

**Application development:** JavaScript · TypeScript · React · Node.js · Flask

**Systems & infrastructure:** PostgreSQL · MongoDB · Redis · Docker · Linux · Git

## How I think

| Principle | What it means in practice |
|---|---|
| **Problem first** | Choose technology based on the problem and its constraints, not hype. |
| **Systems over demos** | Consider data flow, failure modes, security, deployment, and maintenance. |
| **Evidence over claims** | Prefer reproducible setup steps, tests, and measured results over unverified numbers. |

## A little more

I enjoy building practical tools, exploring how software systems fit together, and learning by implementing ideas end to end.

My long-term direction is **GenAI engineering**—especially agentic systems that are useful, inspectable, and reliable.
