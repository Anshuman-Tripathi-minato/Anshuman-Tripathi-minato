## How I think

A good AI agent is not just a prompt. It needs four things, and my projects are where I practiced each one:

| Layer | What it means | Where I built it |
|:--|:--|:--|
| **Ground it in data** | Models are only as good as the signal they see | Satellite crop & drought mapping |
| **Give it tools** | Agents act through system interfaces | Linux toolkit, TaskGlass |
| **Make it reason** | Prediction + optimization, not just charts | Supply chain optimizer |
| **Make it trustworthy** | Privacy, offline-first, user ownership | Decentralized storage, E-Chat, AuraMusic |

Now I'm combining these layers with **LLMs, RAG and MCP** to build agentic systems.
